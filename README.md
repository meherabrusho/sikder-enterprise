# Sikder Enterprise — Official Website

Official dual-role corporate website for **Sikder Enterprise** (*1st Class Contractor & Supplier*), headquartered at 33 Kawran Bazar, Shah Ali Tower (5th Floor), Tejgaon, Dhaka-1215, Bangladesh.

- **Proprietor:** Md Abul Kalam Azad
- **Subcontracting Track:** Heavy civil, structural (rebar, shuttering, concreting), metro rail track works (MRT Line-6 CP-07 with Larsen & Toubro), and skilled manpower supply.
- **Main Contracting Track:** Turnkey residential, commercial, and institutional building construction and material supply across Dhaka, Khulna, and nationwide.

## Architecture & Hosting

Built with zero-dependency semantic HTML5, plain CSS (`css/styles.css`), and vanilla JavaScript (`js/main.js`) for fast, zero-maintenance hosting on **GitHub Pages**.

### Document Security Tiers
1. **Public Reference Documents (`assets/docs/`):** Sanitized Company Profile PDF and Public Works Department (PWD) Schedule of Rates (2022 & 2018).
2. **Verified Prequalification Vault (Request-Only):** Statutory certificates (Trade Licence, TIN/VAT), L&T LOAs/Work Orders, and Bank Solvency documents are kept off the public repository and shared via read-only Google Drive links upon inquiry.

### Optional: Direct Form Emails via Web3Forms
By default, the 3-tab inquiry form prepares a structured email to `akazad1531960@gmail.com`. To send submissions silently in the background without opening the visitor's mail app:
1. Create a free access key at [web3forms.com](https://web3forms.com/) using `akazad1531960@gmail.com`.
2. Paste the key into `WEB3FORMS_KEY` at the top of `js/main.js`.
